# sunday-school

Шпаргалка для урока воскресной школы под телефон: https://dmitriy-kiriyenko.github.io/sunday-school/

Статический сайт без сборки, GitHub Pages публикует корень ветки `main` при каждом пуше.

## Как устроено

- `input/` — исходные документы уроков (полный markdown).
- `lessons/<дата>.json` — выжимка для самого урока: слайды-блоки с пунктами.
- `lessons/index.json` — список id уроков; на главной они сортируются по `date`, свежий сверху.
- `index.html`, `app.js`, `style.css` — приложение; `sw.js` — офлайн-кэш.

## Добавить урок

1. Положить исходник в `input/<дата>.md`.
2. Сделать `lessons/<дата>.json` по образцу существующего и дописать id в `lessons/index.json`.

Формат слайда: `title`, `minutes` (если входит в план — из них считаются проценты и минуты начала),
`kind` (`prep` — до урока, `fork` — развилка, `backup` — запасной, вне плана), `items`, `choices`
(`{label, goto: <id слайда>}`). Пункты: `do`, `ask`, `say`, `read`, `hint` (с `ref`) — с галочкой;
`note`, `warn` — без. В тексте работают `**жирный**` и `*курсив*`.

Локально: `python3 -m http.server` и открыть http://localhost:8000.
